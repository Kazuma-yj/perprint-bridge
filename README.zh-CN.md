# Preprint Bridge

**核对论文发表信息与 CCF 评级，保留你在 Zotero 中的附件与批注。**

[English](README.md) · [下载安装](https://github.com/Kazuma-yj/perprint-bridge/releases/latest) · [反馈问题](https://github.com/Kazuma-yj/perprint-bridge/issues) · [版本说明](releases/1.3.0.md)

Preprint Bridge 是一个面向 **Zotero 10.0.x** 的插件。它帮助你查找预印本对应的正式会议论文或期刊文章，也支持核对已有发表条目的信息。在你确认后更新原条目，同时保留条目 ID、附件、批注、笔记、标签与所属分类。

## 功能

- **查找正式版本**：检索匹配的会议论文或期刊文章，无需 API Key，核对后再更新。
- **补全出版信息**：在来源提供的情况下补全论文集或期刊名称、发表日期、DOI、页码、卷次、ISSN、ISBN、期号、语言和会议地点。识别到的会议使用全称，并附带缩写与年份，例如 `(ICML 2024)`、`(KDD 2026)`。
- **CCF 评级与批量更新**：根据已有会议名或刊名在本地匹配，一次更新多个条目的 CCF 2026 评级。目录中没有简称的期刊也可按全名匹配。内置数据覆盖目录的一部分，无法可靠匹配时不猜测评级。
- **记录录用状态**：支持核对 arXiv 中明确的录用说明，标记为待正式出版，并在日后继续查询。
- **批量核对与差异预览**：多选论文，顺序检索，在同一窗口查看修改前后内容，逐项勾选字段后批量更新。可停止、继续与重试未完成项。
- **窗口内撤销**：关闭核对窗口前可撤销本次更新；遇到后续手动修改时，支持查看差异并主动选择覆盖。
- **返回 arXiv 原文**：条目已经更新为正式版本，也能直接打开原预印本页面。
- **统一的中英文菜单**：各类论文使用相同入口，明确区分正式发表记录、仅录用说明、来源故障和未找到匹配。

## 安装

1. 前往 [Releases](https://github.com/Kazuma-yj/perprint-bridge/releases/latest)，下载 **`preprint-bridge-1.3.0.xpi`**。请选择 `.xpi` 安装包，不是 Source code 压缩包。
2. 打开 Zotero 的 **工具 → 插件**，点击齿轮菜单，选择“从文件安装插件”，打开下载的 XPI。
3. 正常重启 Zotero，确认 Preprint Bridge 已启用。

已经使用本仓库更新地址的版本，可通过 Zotero 的插件更新检查升级。更新地址仍为 `example.com` 的早期版本，需要手动安装一次。自动更新需要能够访问 GitHub。

**兼容范围：Zotero 10.0.x。** 当前清单不支持 Zotero 7/8/9 或 Zotero 11。本版已进行自动化测试，并在官方 Linux Zotero 10.0.3 中安装真实 XPI，验证窗口显示、数据库保存、撤销与插件启停。Windows 和 macOS 尚未实机验证。详见[测试记录](TESTING.md)。

## 使用

右键点击文献主条目，打开 **Preprint Bridge** 子菜单。预印本、已录用论文、正式会议论文和期刊文章使用相同的菜单名称与顺序。不适用的命令会置灰，“使用说明”中可以查看选择条件。

| 命令 | 需要选中的条目 |
| --- | --- |
| 核对并更新出版信息… | 一个或多个预印本、会议论文或期刊文章 |
| 更新 CCF 评级… | 一个或多个会议论文／期刊文章 |
| 高级 → 从已导入条目手动补全… | 自动检索无匹配时：预印本或待正式出版条目 + 已导入的正式版本 |
| 打开 arXiv 原文 | 一个带 arXiv 标识的条目 |
| 使用说明 | 查看各命令的操作方式 |

### 核对预印本或已有发表条目

选择 **“Preprint Bridge → 核对并更新出版信息…”**。在核对窗口中查看每篇论文的来源和字段差异，勾选要更新的论文和字段，再点击“更新勾选的 N 项”。请选中文献主条目，而不是下方的 PDF 附件。不同来源由插件自动判断，操作入口相同。

条目需要填写题名和第一作者。URL、DOI 或“其他”中的 arXiv 标识有助于查找正式版本；没有 arXiv 标识时，也可按题名与作者检索。已有正式 DOI 时优先按 DOI 核对，备用检索不会用其他 DOI 的论文替换它。多篇论文按顺序检索；单篇失败不影响后续条目。关闭窗口或停止队列不会撤销已经保存的修改。

根据发表类型和来源提供的信息，插件可补充以下字段：

| 发表类型 | 出版字段 |
| --- | --- |
| 会议论文 | 论文集标题、会议名称、发表日期、DOI、页码、卷次、ISSN、ISBN、语言、会议地点、正式版本链接 |
| 期刊文章 | 期刊名称、发表日期、DOI、页码、卷次、期号、ISSN、语言、正式版本链接 |

会议名称示例：`41st International Conference on Machine Learning (ICML 2024)`。

“其他”字段只增加简要信息，并保留你原有的备注：

```text
arXiv: 2403.06634
CCF (2026): A (ICML)
```

如果只能确认录用，还会增加 `出版状态：已录用，待正式出版`，保留 arXiv 链接，不虚构正式 DOI。

### 批量核对、覆盖与撤销

- 每个拟修改字段都有复选框，可独立选择出版社、论文集标题、会议名称、DOI、其他等内容；也可“全选字段”或“清空选择”。只保存勾选的字段，保存结果仅列出实际修改。
- 字段默认全选，论文默认不选。直接调整字段会选中该论文；清空全部字段后不能更新。批量勾选论文会保留各篇已选字段。切换候选或重新预览会重置字段选择，需要再次确认论文。
- 条目类型转换必须联动的字段会明确标注；取消类型转换，会取消其关联字段。选择新类型专用字段时会一并选中类型转换。
- 默认不勾选任何论文。“勾选全部正式记录”只选中已找到正式出版记录且有字段变化的论文；仅录用记录需要单独勾选。
- “已找到正式记录”表示规范化题名与第一作者通过匹配；“仅有录用说明”表示依据是 arXiv 作者说明，尚未找到正式出版记录。这些是证据类型，不是置信度分数。
- 成功更新会在窗口内显示“出版信息已更新。作者列表和 PDF 保持原样。”，不再弹出带警告图标的成功提醒。
- 核对后又手改了条目，可点击“按当前内容重新预览…”，检查当前值与拟写入值，再勾选更新。不会永久禁止覆盖。
- “撤销本窗口的更新”恢复本次保存前的条目信息。若有后续手动修改，默认保留；也可以点击“查看后续修改并撤销…”，确认差异后覆盖恢复。
- **撤销记录仅保存在当前窗口，关闭后清除。** 窗口内撤销仅适用于此核对窗口的出版更新；单独的 CCF 命令和高级手动补全不在其范围内。
- 停止会等待当前请求或保存结束，然后停止后续操作。可继续或重试未完成项，已完成的结果保留。

### 自动检索未匹配时

这个高级入口用于检索源尚未收录、或正式版题名有明显变化的情况；正常自动核对不需要它。使用 Zotero Connector 导入正式发表版本。同时选中 **原预印本 + 正式会议论文或期刊文章**，选择 **“Preprint Bridge → 高级 → 从已导入条目手动补全…”**。标题不同时会额外要求确认是否为同一篇论文。两个条目都会保留，是否删除重复条目由你决定。

### 给已有论文批量补充 CCF 评级

选中一个或多个会议论文／期刊文章，选择 **“Preprint Bridge → 更新 CCF 评级…”**，查看匹配结果后确认一次即可。匹配依据是条目已有的会议名或刊名，使用本地 CCF 目录，不需要重新联网检索论文。

此操作只更新“其他”字段中的 CCF 标记，保留其他出版字段、个人备注和录用状态。无法可靠匹配、只读或正在处理的条目会跳过，完成后显示统计。目录中没有简称的期刊使用 `CCF (2026): B` 这样的简短标记。

### 打开原预印本页面

选择 **“Preprint Bridge → 打开 arXiv 原文”**。更新为正式版本后，“其他”中保留的 arXiv 标识仍可用于返回原文。

### 更新哪些内容

核对窗口只在原条目上写入你勾选的字段。来源缺少页码、卷次或 DOI 时，会保留已有值；转为正式发表记录时会提出移除 arXiv DOI，是否保存由字段勾选决定。“其他”中的个人备注会保留，旧版本插件生成的冗长信息会被精简。

**原作者列表和 PDF 文件不会替换。** 请对照正式版本核对作者和 PDF，尤其注意预印本与正式版本的作者变化。插件不下载替换 PDF、不跨 PDF 迁移批注、不合并条目，也不自动删除重复条目。

### 为什么找到正式页面后仍有空字段？

正式出版记录不一定提供 DOI、ISBN 或期号。“出版字段无需修改”只表示来源已提供的字段与条目一致，不代表所有栏位齐全。没有可靠来源的数据不会凭空填写，也不会把 arXiv DOI 当作正式 DOI。

例如 `Auditing Prompt Caching in Language Model APIs` 的官方页面提供 ISSN `2640-3498`，卷册页面提供温哥华会议地点，本版可读取并预览补全；页面与推荐引用没有提供正式 DOI 或 ISBN。会议地点写入“会议地点”，不会混填为出版社的“地点”。[论文页](https://proceedings.mlr.press/v267/gu25b.html) · [卷册页](https://proceedings.mlr.press/v267/)

## 匹配规则

自动匹配要求规范化后的题名与第一作者一致。允许正式版本增加 `Position:` 或 `Position Paper:` 前缀；其他实质性题名变化请使用双条目手动复制流程。

会议论文和期刊文章通过 DBLP（含其官方 SPARQL 服务）与 Crossref 检索，arXiv 提供预印本与录用说明。覆盖范围取决于来源的收录情况，以及候选记录能否通过匹配检查。各来源可能收录不全或暂时无法访问，**未找到匹配不等于论文尚未发表**。

同一核对入口还会读取已适配的出版页面，并可直接查询附近年份的 ICML 论文集。目前 PMLR 页面有专用解析，其他出版平台主要通过 DOI 或检索源获取元数据，因此字段完整度可能不同。已验证的样本包括 ICML、ICLR、NeurIPS、NAACL 会议论文，以及 Machine Learning、Nature 期刊文章，详见[测试范围](TESTING.md)与[数据来源](DATA_SOURCES.md)。

CCF 标签统一使用 **2026 版目录，包括对早年论文的查询**。评级针对会议或期刊，不针对单篇论文。未收录或存在歧义时不自动填入。数据范围与来源见 [DATA_SOURCES.md](DATA_SOURCES.md)。

## 隐私与网络

只有执行相应命令时，插件才查询论文信息。根据检索路径，公开服务会收到论文题名、第一作者姓氏、DOI 和／或 arXiv 标识；插件也会读取匹配到的出版页面。插件不上传笔记、批注、PDF 内容或整个文献库，无遥测，不需要插件账号。

CCF 匹配在本地完成。部分公开目录数据会临时缓存在内存中，减少重复请求。Zotero 的插件更新机制会访问 GitHub 上的更新信息。请求设有超时。批量核对按来源间隔请求；遇到 HTTP 429 时，该来源在当前窗口内暂停请求至少 60 秒，其他来源仍可继续。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 右键没有 Preprint Bridge 菜单 | 确认插件启用、退出 Zotero 安全模式，并选中文献主条目。 |
| 命令为灰色 | 按上表检查选择条件，并确认条目可编辑、未在处理中；菜单内“使用说明”也有解释。 |
| 提示缺少第一作者 | 补全作者字段，或导入正式版本后手动复制信息。 |
| 检索等待较久 | 窗口会显示队列进度；可停止，稍后继续未完成项。 |
| 提示“检索未完成”或返回 HTML | 来源可能返回故障页或验证页。稍后重试，或导入正式版本后使用手动复制。 |
| 没有 CCF 评级 | 可能未列入目录、不在内置数据子集中，或缩写存在歧义；请核对官方目录。 |
| 自动更新失败 | 检查 GitHub 访问情况，必要时从 Releases 手动安装新版 XPI。 |

遇到可复现的问题，请[提交 Issue](https://github.com/Kazuma-yj/perprint-bridge/issues/new/choose)，提供 arXiv 标识、Zotero 与插件版本、预期结果和相关日志。公开日志前请删除私人信息。
