# Preprint Bridge 1.3.1

## 中文

修复仓库更名后遗留的地址和发布配置。

- 仓库链接统一为 `Kazuma-yj/preprint-bridge`，涵盖中英文说明、问题反馈、插件主页和自动更新地址。
- 修正 GitHub Actions 的仓库判断以及发布脚本，恢复 main 分支通过检查后的自动发布。
- 更新构建、安装包校验和相关测试中的仓库地址。
- 发布新的 XPI，使安装包内的主页和更新地址同步生效。插件标识保持不变，可从旧版升级。

此版本不改变论文检索、字段更新或 CCF 评级逻辑。兼容 Zotero 10.0.x。旧版若无法自动更新，可从本仓库 Releases 手动安装新版 XPI。

## English

Fix repository URLs and release configuration after the repository rename.

- Use `Kazuma-yj/preprint-bridge` in documentation, issue links, the plugin homepage and update URLs.
- Fix the repository guards in GitHub Actions and the release script so validated main pushes can publish releases.
- Update build, package verification and related test URLs.
- Ship a new XPI containing the corrected homepage and update URL, preserving the add-on ID for upgrades.

Publication lookup, field updates and CCF matching are unchanged. Supports Zotero 10.0.x. If an older installation cannot update automatically, install the new XPI from this repository's Releases page.
