# Preprint Bridge 1.2.0

## 中文

- 多篇论文排队核对，在一个窗口查看字段修改前后的差异，勾选后批量更新。
- 支持停止、继续、重试未完成项，单篇检索或保存失败不阻断其他条目。
- 清楚区分“正式出版记录”和“仅有录用说明”。成功状态在窗口内显示，不再弹出警告图标或含糊的“请核对”提示。
- 新增窗口内撤销。手改内容默认受到保护；想覆盖时，可重新预览当前差异后更新，或明确确认覆盖后撤销。
- 手动补全移到“高级 → 从已导入条目手动补全…”，作为检索无匹配、正式版改名时的备用入口。
- 按来源间隔请求；遇到 429 后暂停该来源的请求，减少批量操作中的重复限流。
- 增加队列、撤销、覆盖冲突、保存失败和真实 XHTML 窗口交互测试。

安装 `.xpi` 后，选中一篇或多篇文献主条目，右键选择 **Preprint Bridge → 核对并更新出版信息…**。
作者、PDF、批注保持原样。撤销记录只保留到关闭核对窗口；仅覆盖此窗口内的出版信息更新。

## English

- Queue multiple papers, compare before/after fields in one review window, then update selected records.
- Stop, continue and retry unfinished items; individual lookup/save failures do not stop the batch.
- Distinguish formal publications from acceptance notes. Success is shown inline without a warning-style alert.
- Undo publication updates while the review window remains open. Manual edits are protected by default; fresh differences and explicit confirmation allow intentional overwrites.
- Move manual metadata transfer to **Advanced → Complete from an imported record…** as a fallback for unindexed or renamed publications.
- Pace requests by source and cool down rate-limited hosts after HTTP 429.
- Add queue, undo, conflict, save-failure and actual XHTML interaction tests.

Select one or more bibliographic parent items, then use **Preprint Bridge → Review and update publication…**.
Authors, PDFs and annotations stay in place. Undo history ends when the window closes and covers only its publication updates.

See [TESTING.md](https://github.com/Kazuma-yj/perprint-bridge/blob/main/TESTING.md) for coverage and desktop-validation limits.
