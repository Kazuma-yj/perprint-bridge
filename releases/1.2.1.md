# Preprint Bridge 1.2.1

## 中文

修复点击“核对并更新出版信息…”后出现空白窗口的问题。

- 将核对窗口注册为 Zotero 的 `chrome://` 资源。1.2.0 使用 XPI 内部的 `jar:file:` 路径打开原生窗口，会停在 `about:blank`。
- 禁用、升级和启动失败时释放资源注册，重新启用后可正常打开。
- 发布流程新增真实 Zotero 10.0.3 测试：先复现 1.2.0 白屏，再验证新版窗口、差异预览、数据库保存、撤销、关闭后重开与禁用/启用。

1.2.0 的 Chromium 测试未覆盖原生窗口加载。此次已在官方 Linux Zotero 10.0.3 中安装真实 XPI 验证；Windows 与 macOS 尚未实机验证。

安装新版后重启 Zotero。批量核对、主动覆盖和撤销功能保持可用。

## English

Fix the blank window opened by **Review and update publication…**.

- Register the review document as a Zotero `chrome://` resource. The 1.2.0 `jar:file:` window URL left the native window at `about:blank`.
- Release chrome registration on disable, upgrade and failed startup; re-enabling restores it.
- Add a real Zotero 10.0.3 release gate: reproduce the old blank window, then test the current XPI’s rendering, field preview, database save, undo, reopen and disable/enable lifecycle.

The 1.2.0 Chromium suite did not cover native window loading. This fix was exercised with the actual XPI in official Linux Zotero 10.0.3; Windows and macOS have not been tested on-device.

Restart Zotero after installing this update. Batch review, intentional overwriting and undo remain available.
