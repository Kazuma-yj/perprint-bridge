# Preprint Bridge 1.3.0

## 中文

核对窗口现在可以逐个勾选字段。例如只更新会议名称，同时保留手写的出版社和论文集标题。

- 新增字段复选框、全选与清空；批量选择论文不会重置各篇的字段选择。保存结果只显示实际更新的字段，仍可在窗口内撤销。
- Zotero 条目类型转换必须关联修改的字段会联动并明确标注；保存前检查，防止隐式修改未勾选内容。
- 补读官方页面中的 ISSN、ISBN、语言及卷册中的会议地点。DBLP 提供 DOI 链接时，继续按同一 DOI 获取 Crossref 的详细信息，包括期号、标识符和会议地点。
- 明确区分“来源未提供 DOI”和“检索失败”；“出版字段无需修改”不再暗示所有信息都已齐全。
- 修复截图中的 ICML 2025 论文遗漏 ISSN 和会议地点的问题。其官方页面与推荐引用未提供 DOI 或 ISBN，保持空白，不编造标识符。

通过 Node 回归测试，并在官方 Linux Zotero 10.0.3 中安装实际 XPI，验证只选会议名称、保留未选字段、补全 ISSN/会议地点、撤销及插件启停。Chromium 界面交互与原生 Zotero 测试均为发布前置检查。Windows/macOS 尚未实机验证。

## English

Choose individual fields in the review window—for example, update the conference name while keeping a manually entered publisher and proceedings title.

- Add per-field checkboxes, select-all and clear controls. Batch paper selection retains field choices. Saved results show only actual changes, with session undo available.
- Mark and link Zotero’s required item-type conversions; reject implicit changes to unchecked fields before saving.
- Read publisher-supplied ISSN, ISBN and language, and PMLR conference locations. Enrich DBLP DOI links through the matching Crossref DOI record, including issue and additional citation fields.
- Explain missing DOI separately from lookup failure. “No field changes” means available fields match, not that every field is complete.
- Recover the reported ICML 2025 paper’s ISSN and conference location. Its official page and recommended citation do not supply a publisher DOI or ISBN; neither is fabricated.

Node regression tests and actual-XPI tests in official Linux Zotero 10.0.3 cover selective saving, untouched unchecked values, additional fields, undo and lifecycle. Chromium interaction and native Zotero checks gate publication. Windows/macOS have not been tested on-device.
