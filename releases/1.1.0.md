# Preprint Bridge 1.1.0

## One menu for every paper

Right-click a bibliographic parent item and open **Preprint Bridge**:

- **Review and update publication…** — one entry for preprints, accepted papers,
  published conference papers and journal articles. Available DOI metadata is
  checked directly. Publication-page handling is selected automatically.
- **Update CCF rating…** — match existing conference/journal names locally,
  review once, and update one or multiple items. Only CCF labels in Extra change.
- **Copy published metadata to preprint…** — select a preprint and an imported
  publication together, then review the transfer.
- **Open arXiv preprint** — return to the original page even after publication
  metadata replaced the item's URL.
- **How to use** — explains selections and disabled commands.

Commands keep their names and positions across paper types. Unsuitable commands
are disabled rather than hidden. The old separate PMLR refresh command is now
part of the unified publication-review command.

## Additional improvements

- CCF full-title matching now includes 46 journals without directory abbreviations,
  bringing the extracted dataset to 657 rows. Uncertain matches still abstain.
- Existing publication DOIs constrain fallback results, and a published record
  cannot be replaced with acceptance-only metadata.
- Same-publication refreshes preserve an existing conference name when the new
  source lacks one. A DOI URL change does not discard an existing detailed date.
- Disable/re-enable clears stale busy state. Cancelling or disabling during a
  review prevents subsequent writes; batch failures restore the failed item's
  Extra value and report the outcome.

Validation: 57 automated tests and 11 real-metadata workflow cases (10 distinct
papers), including three newly fetched DOI records. Final replay uses cached
responses. Full desktop UI validation remains outstanding; see `TESTING.md`.

Download `preprint-bridge-1.1.0.xpi` below, install through Zotero's Plugins menu,
and restart normally. Existing installations can also use Zotero's update check.
Requires Zotero 10.0.x. Existing PDFs and author lists are retained.

## 中文说明

### 统一右键菜单

现在所有论文都使用 **Preprint Bridge** 子菜单：

1. **核对并更新出版信息…**：预印本、已录用论文、正式会议论文和期刊文章共用一个入口，已有 DOI 时优先按 DOI 核对。
2. **更新 CCF 评级…**：支持多选，本地匹配已有会议名或刊名，确认一次后仅更新“其他”中的评级。
3. **复制正式版本信息到预印本…**：同时选中原预印本与正式版本条目后核对复制。
4. **打开 arXiv 原文**：更新为正式版本后，也能返回原预印本页面。
5. **使用说明**：查看操作方式和选择条件。

菜单名称和位置保持一致，不适用的命令置灰。原“重新核对 PMLR”已经并入统一核对入口。

同时补入 46 条没有简称的期刊记录，CCF 数据增至 657 行；完善 DOI 一致性检查、取消与重新启用处理。
57 项自动测试通过；11 条真实元数据流程用例通过，涉及 10 篇不同论文。桌面界面仍需完整客户端验证。

下载 `.xpi` 后在 Zotero“工具 → 插件”中安装并正常重启，或使用插件更新检查升级。
