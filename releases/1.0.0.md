# Preprint Bridge 1.0.0

Find published versions of arXiv papers in Zotero 10.0.x. Review the source and
metadata before updating the original item, retaining attachments and annotations.

## Highlights

- Publication lookup through arXiv, PMLR, DBLP (including its official SPARQL
  fallback), and Crossref; no API key or Semantic Scholar dependency.
- Detailed proceedings metadata, conference abbreviations with years, concise
  Extra fields, and local CCF 2026 venue rankings.
- Provisional acceptance tracking, manual transfer from an imported publication,
  and a refresh command for existing PMLR records.
- New search progress feedback and early checks for read-only items and missing
  first authors. A failed PMLR directory is requested once per search attempt.
- Sparse source records preserve existing DOI, pages, volume and detailed dates
  where applicable. Invalid DBLP links no longer discard other valid results.
- Corrected CCF PDF table extraction to prevent adjacent rows corrupting venue
  names. The bundled partial dataset contains 611 rows; ambiguous matches abstain.
- Public English and Chinese documentation, reproducible package verification,
  and a release workflow that verifies assets before publication.

## Install / update

Download `preprint-bridge-1.0.0.xpi` below and install it through **Zotero → Tools →
Plugins → Install Plugin From File…**, then restart Zotero normally.
Existing installations with the repository update feed can use Zotero's update
check. Builds with the old `example.com` update address need manual installation.

CCF labels use the 2026 directory even for older papers. The plugin keeps the
original author list and PDF; review both against the final publication.
See `TESTING.md` in the repository for automated and real-paper validation.
Full desktop UI testing across Windows, macOS and Linux remains outstanding.

## 中文说明

这是 Preprint Bridge 的 1.0.0 公开版本，支持 Zotero 10.0.x。

- 核对 arXiv 论文的正式发表或明确录用信息，确认后更新原条目，保留附件与批注。
- 补全会议名称、缩写与年份，显示 CCF 2026 评级，精简“其他”字段。
- 支持手动复制正式版本信息，以及重新核对已有 PMLR 条目。
- 增加检索等待提示、只读条目和缺失作者检查；优化故障目录的重复请求。
- 来源信息不完整时保留已有 DOI、页码、卷次和适用的详细日期。
- 修复 CCF 表格提取中的串行文字问题，纠正会议名称；内置 611 行部分目录数据。
- 重写中英文使用文档，加入安装包校验和自动发布流程。

下载下方 `.xpi`，在 Zotero“工具 → 插件”中从文件安装，正常重启即可。
请核对正式版本的作者与 PDF：插件不会替换作者列表或 PDF 文件。
自动测试及真实论文验证记录见仓库 `TESTING.md`；尚未完成各操作系统的完整桌面界面测试。
